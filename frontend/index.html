Kiểm tra nội dung báo cáo

Tìm đoạn tương đồng và đối chiếu trực tiếp với tài liệu nguồn.

Thiết lập kết nối PostgreSQL

  1. Sao chép .env.example thành .env, nhập tên database, tài khoản và mật khẩu.
  2. Chạy python -m app.db init để tạo bảng dữ liệu.
  3. Khởi động lại web và bấm “Làm mới dữ liệu”. Xem docs/WEB_POSTGRESQL.md để tạo database.
